# SWPlus TT: пресеты и программный вызов

Это обязательный маршрут оформления технических требований детали/сборки. Содержание требований определяется исходной КД и технологией, оформление — инструментом SWPlus TT. Общая библиотека инструмента не изменяется ради одного изделия.

## Установленный пакет

Корень: `<инструментарий>\03_Макросы_и_Плагины\Макросы_SW_ZTool\SWPlusMacro_v_2018_SP0.0\ТТ`, где `<инструментарий>` — `<СЕТЬ_КО>\_Библиотека проектирования\_инструменты_конструктора` или его локальная установка `%LOCALAPPDATA%\ESKD\Toolkit` (у владельца — `<WORK>\06_Справочники_и_шаблоны\03_SolidWorks_шаблоны_и_библиотеки`).

- `TT.SWP` — штатный запуск менеджера; в проверенной версии `Run_Program.main` лишь запускает `TT.EXE` и активирует окно. Не считать его headless API и не запускать его для обхода ограничения на управление интерфейсом.
- `TT_Prof.txt` — действительные комплексные пресеты; `TT.TXT` — база отдельных требований. Читать в Windows-1251. Для следующего рабочего места путь искать в установленном инструментарии, проверять наличие и хеши.
- `apply_tt_profile.py` — программный инструмент пакета, описанный в `06_Документация\ТЕХНИЧЕСКИЕ_ТРЕБОВАНИЯ_ГОСТ_ЕСКД.md`, раздел «Автоматизация». Использовать его профильную логику и стандарт оформления, а не собственный блок заметок. В текущей версии он подключается через глобальный `GetActiveObject`; перед пакетным применением нужен адаптер к явно выбранному CAD-сеансу, проверенному документу и типизированным COM-методам. Глобальный CLI с `--save` в нескольких CAD-сеансах не запускать.
- `Добавление ТТ.swp` — другой макрос с фиксированными тремя пунктами на всех листах, без выбора пресета; он не выполняет требование использовать SWPlus TT с соответствующим пресетом.

Успех записи через `CreateText2` внутри проверенного штатного инструмента допустим. Отдельный собственный `InsertNote`/`CreateText2` вместо вызова этого инструмента не является применением SWPlus TT.

## Выбор пресета

Точные имена подтвердить по текущему `TT_Prof.txt`. Обнаруженные 10.10.2026 варианты:

| Вид документа / технология | Пресет |
|---|---|
| Листовая деталь без гибки | `Деталь: Лазерная резка (листовой металл)` |
| Листовая деталь с гибкой | `Деталь: Лазерная резка + Гибка` |
| Толстый лист с плазменной резкой | `Деталь: Плазменная резка (толстый лист)` |
| Токарная деталь | `Деталь: Токарная обработка` |
| Фрезерная деталь | `Деталь: Фрезерная обработка (ЧПУ)` |
| Токарно-фрезерная деталь с подтверждёнными ТО и покрытием | `Деталь: Токарно-фрезерная с ТО и покрытием` |
| Труба/прокат, отрезка | `Деталь: Сортовой прокат / Труба (отрезка в размер)` |
| Сборка со сваркой УП | `Сборка: Сварка полуавтоматическая в CO2 (ГОСТ 14771-УП)` |
| Сборка со сваркой ИП | `Сборка: Сварка полуавтоматическая в смеси Ar+CO2 (ГОСТ 14771-ИП)` |
| Сборка со сваркой АП | `Сборка: Сварка автоматическая в защитном газе (ГОСТ 14771-АП)` |
| Сварная рама из профилей | `Сборка: Сварная рамная конструкция из профильных труб` |
| Механическая сборка | `Сборка: Механическая сборка (без сварки)` |

Пресет — основа, а не доказательство применимости всех его пунктов. Например, «Сварная рамная конструкция» включает катет 4 мм и RAL 7035; «Механическая сборка» — Loctite 243 и Циатим-221; «Лазерная резка + Гибка» — R = s. Не переносить эти назначения без подтверждения. Специальные требования модели и исходного чертежа сохранить; из базы отдельных требований выбирать применимые пункты, записывая изменения к базовому профилю.

## Приёмка

1. Сохранить прежний чертёж/PDF, получить фактический формат через DProp и определить существующий блок ТТ.
2. Выбрать профиль по модели и технологии, сверить применимые пункты; выполнить проверенный программный вход SWPlus TT. При невозможности вызова не выставлять `tt_applied=true`.
3. Проверить стандартное оформление, переносы, ширину и зазор до основной надписи по фактическому тексту. Не оценивать высоту блока только по количеству пунктов: один пункт может занимать несколько строк.
4. Сохранить, закрыть и снова открыть SLDDRW. Проверить отсутствие дубля ТТ и сохранность прочих аннотаций; экспортировать нативный PDF/снимок и осмотреть лист целиком.
5. Записать в папке изделия выбранный профиль, базу и её хеш, инструмент/программный вход, фактически применённые пункты, изменения к профилю и результаты проверки после открытия. Успешный вызов без проверки размещения не завершает оформление.
