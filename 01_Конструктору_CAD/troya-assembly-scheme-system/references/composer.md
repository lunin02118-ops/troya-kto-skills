# SOLIDWORKS Composer: как делали

Проверено на Composer 2025 SP03, сборка 7.12.4.25342, Windows. Парта NOMAD V и Spider сделаны через COM. Стул NC3-7R (10–13.11.2026) сделан командной строкой, без COM. На другой версии Composer сначала посмотреть библиотеку типов: подписи методов могут отличаться.

## Проект из копии сборки

- Сборку поставки скопировать в `CAD_копия` и работать только с копией. SHA-256 копии записать до начала и сверить после.
- Командная строка (стул NC3-7R): `composer.exe -merge <список.xml> <проект.smg>`, где список — `<Merge><File>путь к .SLDASM</File></Merge>`. Код — `examples/nc3-7r_chair/composer_import_cli.py`. Готовый `.smg` не перезаписывать: прежний переносить в «Архив».
- Если проект уже есть — продолжать его. Импорт заново — только если изменилась геометрия и это записано.
- Дерево актёров, пути, положения и габариты читаются из `product.smgXml` внутри `.smg` (это zip). Код — `smg_tree.py`, только чтение.

## Виды без COM (стул NC3-7R)

- `composer_views.py` пишет файл видов `.smgView` (XML). Для каждого вида в нём камера, видимые детали, цвет, контур и положение верхних актёров. Сценарий видов — `scenario.py`.
- Блоки Navigator и Viewport берутся из принятого проекта. Для стула взят `.smgView` проекта Spider. Для нового изделия шаблоном берётся `.smgView` своего или любого принятого проекта.
- Рядом пишется `Данные/views.json`: камеры, стрелки и отметки узлов для вёрстки.

## Через COM (парта NOMAD V)

- `comtypes.client.GetModule(<composer.exe>)`, затем `CreateObject('DSComposer.Application', interface=generated.IApplication)`. Позднее связывание pywin32 нужные методы документа не давало.
- Если ProgID на ПК не зарегистрирован, Composer запускают с ключом `-Embedding` и подключаются по CLSID. Библиотеку типов записывают для текущего пользователя (RegisterTypeLibForUser, без прав администратора). Код — `composer_com.py`.
- Скрипты COM и запись библиотеки типов в реестр запускать из обычного окна cmd или через explorer.exe. Из терминала агента в Claude Desktop запись в реестр уходит в его собственный слой.
- Перед правкой сохранить копию `.smg` и файл видов `.smgView`.
- `SetPropertyMap` восстанавливает сохранённые `Actor.Location`. Выбор актёров: `<CLitSelection>actorId#actorId#</CLitSelection>`.
- `SetVisibility(выбор, 1, 2)` оставляет видимыми только выбранных актёров (в этой сборке Composer; результат сверять со сценой).
- `TranslateInWCS` и `RotateInWCS` двигают актёров Composer, а не модель SolidWorks. Если узел показан повёрнутым, повернуть и оси установки.
- Ортокамера: `Navigator.Camera.Location` (Frame, Pivot), `Navigator.Camera.Height`, `Navigator.Camera.Proj.Persp = 0`. Перевод координат CAD → лист записать. Стрелки считать от той же камеры, что и рисунок.
- `UpdateView` возвращал False. Работает так: `DeleteView('ref:guid:' + id)`, затем `CreateView(имя, номер)`. **Удаление вида меняет сцену.** После него вернуть положение актёров, видимость и камеру, и только потом создавать вид.
- Сохранить `.smg` и выгрузить все виды. Закрывать только свои документы и свой процесс: записать его PID, время запуска и путь. Все процессы Composer разом не закрывать.

## Выгрузка SVG

- Команда: `composer.exe -generateImage <проект.smg> <settings.xml>`. В настройках — `Batch.SaveFolder`, `Batch.IOSmgViewFile`, `Batch.LogFilePath` и профиль векторизации. XML сохранять в UTF-8.
- Профиль — «HLR + Flat color»: `…\SOLIDWORKS Composer\Profiles\VectorizeProfiles\HLR + Flat color.smgVectoSet`.
- Каждый раз — новая папка `Composer/svg-<время>`. Для точечной правки выгружать только нужные виды.
- Код выхода 1 и 11057 бывает и при успехе. Проверять сами файлы: каждый ожидаемый есть, новее запуска, читается как SVG и на нём видна геометрия. Старый SVG новую выгрузку не подтверждает.
- Растровый `SaveImage` давал чёрные картинки. Векторная выгрузка шла с временной настройкой программной отрисовки. Прежнее значение сохранить и вернуть в `finally`; настройки пользователя ради удобства не менять.
- Из SVG перед вставкой убрать скрипты и обработчики событий. Исходный SVG сохранить.
- Стрелки и круги-отметки — это наложения при вёрстке, посчитанные от камер видов, а не стрелки-актёры Composer. Это записать в сдаваемый проект.

## Карточки деталей (SolidWorks)

- `render_cards_sw.py` запускает свой процесс SolidWorks (`SLDWORKS.exe /r`) и открывает копию сборки только для чтения. Закраска, камера [1, 1, 0.7], белый пластик, `SaveBMP` 2000 × 1600. Ничего не сохраняет.
- `cards_post.py`: обрезка с полем 20 по порогу 240, боковины поворачиваются на 90°, белый фон становится прозрачным (яркость ≥ 253), оттенок освещения снимается (серый по яркости). Выход — `card_part_<ключ>.png`.
- `sw_calibrate.py` подбирает вид металла по образцу на копии детали. Если SolidWorks молчит дольше 150 с, сторож закрывает только свой процесс (свой PID).

## Продолжение после перерыва

Вести журнал: SHA исходников, какие виды затронуты, какие файлы вышли, какие проверки прошли. Если правка касается только камеры или карточки, не повторять импорт CAD, тесселяцию, перестройку узлов и создание всех видов. Старые диагностические скрипты — это история, а не очередь на повтор.
