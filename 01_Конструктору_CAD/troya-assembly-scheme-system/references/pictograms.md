# Пиктограммы и знаки ISO

Набор общий для всех схем TROYA. Пиктограммы парты NOMAD V (SVG) и стула NC5-7V (PDF и PNG) совпадают один в один — сверено 14.11.2026.

| Имя | Что показывает | Где ставить | Форматы |
|---|---|---|---|
| hex | шестигранный ключ с подписью размера («5 mm») | у узла с винтами под шестигранник; на обложке | svg, pdf, png |
| ph2 | крестовая отвёртка PH2 | у узла с саморезами; на обложке | svg, pdf, png |
| two-person | собирать вдвоём | обложка; шаг с переворотом или тяжёлой деталью | svg, pdf, png |
| soft-pad | положить на мягкую подкладку | обложка; шаг, где столешница или сиденье лежат лицом вниз | svg, pdf, png |
| ruler | измерить линейкой, мм | шаг установки размера или высоты | svg, pdf, png |
| level | пузырьковый уровень | выставить изделие по уровню | svg, pdf, png |
| level-check | проверить уровнем в двух направлениях, под 90° | последний шаг, проверка (Spider) | только svg |
| lower-stop | опустить обе опоры до нижнего упора «MIN», одинаково | опоры, регулируемые по высоте (NOMAD V) | svg, pdf, png |
| transport | транспортный винт: 1 — снять гайку; 2 — вывести винт так, чтобы конец утонул на 1–2 мм; полностью не вынимать | подготовка механизма (NOMAD V) | svg, pdf, png |

## Где какие файлы

- `assets/pictograms/svg/<имя>.svg` — исходник. Подпись «5 mm» в `hex.svg` без встроенного шрифта, и MuPDF рисует её шрифтом с засечками. Для PDF брать файл pdf.
- `assets/pictograms/pdf/pic-<имя>.pdf` — для вёрстки PDF, шрифты встроены. Размер на листе 110 × 69 pt.
- `assets/pictograms/png/pic-<имя>.png` — для Word (паспорт ПС/РЭ) и веба.

## Правила

- Ставить пиктограмму у того узла, где инструмент нужен, а не строкой «все инструменты».
- Своих пиктограмм не рисовать. Нужна новая — согласовать с владельцем и добавить в навык во всех трёх форматах.
- Размер ключа на `hex` — для своего изделия. Другой размер — новая пиктограмма в навыке, а не правка на одном листе.

## Знаки ISO 7000

| Файл | Номер | Значение |
|---|---|---|
| `ISO7000-0001.svg` | 0001 | ограниченное прямолинейное движение (до упора) |
| `ISO7000-0004.svg` | 0004 | направление непрерывного вращения |
| `ISO7000-0005.svg` | 0005 | вращение в обе стороны |
| `ISO7000-0006.svg` | 0006 | ограниченное вращение |

- Источник — Wikimedia Commons, автор Clemenspool, лицензия CC0-1.0. Номер и название сверены с открытым образцом ISO 7000:2004. Это не сертификация всей инструкции.
- Ссылки и SHA-256 — в `assets/symbols/ISO-SYMBOLS.json`. Поле `asset` в нём — путь от папки `assets`.
- SHA-256 в реестре — от файлов, скачанных с Wikimedia; они лежат в `assets/symbols/original`. В `assets/symbols` — облегчённые копии из выпуска парты NOMAD V, их и ставить на лист.
- Номер ISO есть только у этих четырёх знаков. Пиктограммам инструмента и рисункам действий номер не придумывать.
- На листе вращение показывать дугой на самой детали (см. `style.md`), а не отдельным знаком рядом. Легенду знаков в комплект не добавлять.
- Перечёркнутый груз был убран — не возвращать.
