# Сценарий схемы (JSON)

Это формат образца NOMAD V для веб-просмотрщика и вёрстки, а не стандарт CAD. Другой просмотрщик может иметь свою схему, если хранит те же сведения. Стул NC3-7R держит то же самое в `scenario.py` (Python).

| Поле | Что |
|---|---|
| `units` | `mm` — вся геометрия, разносы, камеры и габариты в одной системе |
| `parts` | группы поставки: `id`, `cad_name`, `cad_leaves` (экземпляры CAD этой группы), `position`, `bounds` (два угла), у крепежа — `axis`. Заводская начинка остаётся в своём узле |
| `inventory` | позиции комплекта: `key`, `name`, `code`, `qty` (всего). Заводской и транспортный крепёж записывать отдельно от свободного в пакете |
| `steps` | шаги подряд: `step`, название и описание для автора, `required_parts` (карточки `key`, `qty`), `tools`, проверки, `camera` (`pos`, `target`), `actions` |
| `actions` | `part`, `offset` (разнос), `axis`, `spin` (поворот). Конечное положение берётся из модели. Повторное действие может двигать уже подготовленную группу |
| `phase: [начало, конец]`, `show_after` | порядок внутри шага, например вал [0; 0,4], вторая опора [0,4; 0,7], крепёж [0,7; 1]. Нужен `custom_phases`. Это время показа, а не расчёт контактов |
| `isolated_parts` | подготовительная группа без изделия |
| `staging` | временное положение и поворот отдельного узла; оси установки повернуть так же |
| `upright` | только ориентация показа изделия |
| `open_questions`, `release_status` | открытые факты и статус. Вопрос не снимается сам по прошествии времени |

Для подшагов на нескольких листах держать соответствие «действие → карточки» и в вёрстке. Список карточек широкого веб-шага не копировать на каждый печатный подшаг.

## Проверка

```
python scripts/validate_scenario.py <сценарий.json> [--output отчёт.json]
```

Код 0 — сценарий годен, 1 — есть ошибки. Проверка ловит неизвестные id, перевёрнутые габариты, нулевые оси, неверные количества и интервалы фаз, а также «утверждено» при открытых вопросах. Доступ рук и инструмента, выбор отверстия, настоящие размеры и порядок сборки проверяются по модели и глазами.

Образец — `examples/nomad_v_desk/assembly_guide.json`.
