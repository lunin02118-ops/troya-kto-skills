# Навыки агентов для конструктора TROYA

Это навыки для ИИ-агентов: Claude Code, Codex и Antigravity (Gemini). Агент с ними оформляет чертежи по ЕСКД в SolidWorks,
работает с КОМПАС-3D, раскладывает файлы заказа по ТЗ-03, проверяет технологичность, готовит заявки в цеха.

## Как настроить рабочее место

Откройте агента на ПК сотрудника, под его учёткой Windows, и вставьте задание. Сотрудник работает в PDM: вид хранилища стоит, он вошёл
своей учёткой PDM и получил последнюю версию папки `Навыки_агентов`; путь — от своего вида, пример для `<вид>`:

```
Настрой это рабочее место КТО TROYA. Прочитай целиком и выполняй по шагам инструкцию:
<вид>\02_Библиотека проектирования\Навыки_агентов\01_Конструктору_CAD\troya-workstation-setup\SKILL.md
Сотрудник: <ФИО или логин>.
```

Сетевой диск для работы не нужен (решение владельца 14.11.2026): пакет навыков лежит в хранилище. Путь не открывается — папка не получена
в вид: правой кнопкой по `Навыки_агентов` → «Получить последнюю версию».

Агент определит состав по роли, поставит навыки, проведёт через клиент PDM и набор ЕСКД, скажет, что делает человек
(пароли, окна администратора), и соберёт отчёт о приёмке.

## Как поставить только навыки

1. Нужны Python 3 и хотя бы один агент на ПК.
2. Запустить `Установить.cmd` из папки пакета. В виде хранилища это `<вид>\02_Библиотека проектирования\Навыки_агентов` — сначала
   правой кнопкой по ней «Получить последнюю версию».
   Чтобы сначала посмотреть, что изменится, запустите `Проверить.cmd`.
3. Перезапустить агента.

Прежние копии навыков агент не теряет: они сохраняются в `.skill-sync-backups` внутри папки навыков агента.

## Что нужно на ПК для работы навыков

- **Инструментарий конструктора** (макросы SWPlus, шаблоны, библиотека материалов) ставится из вида хранилища:
  `<вид>\02_Библиотека проектирования\_инструменты_конструктора` (навык `troya-workstation-setup`, шаг 3). Навыки находят его там же или в локальной установке.
- **Заказы** — на сервере, в `<СЕТЬ_КО>\_Заявки`. Порядок папок — навык `kto-folders`.

## Навыки

| Навык | Что делает |
|---|---|
| `eskd-drawings` | чертежи деталей и сборок по ЕСКД в SolidWorks: размеры, швы, позиции, ТТ, спецификация |
| `solidworks-drawing-operator` | подготовка и проверка чертежей SolidWorks |
| `kompas-mcp-operator` | работа агента с КОМПАС-3D через MCP |
| `cad-assembly-structure-organizer` | файлы сборки и проверка CAD-ссылок |
| `cad-material-assignment-system` | назначение материалов по геометрии детали |
| `kto-folders` | папка заказа по ТЗ-03 и раскладка файлов |
| `cad-requests-management-system` | аудит и порядок в `_Заявки` |
| `troya-production-documentation-system` | заявки в цеха: раскрой, сварка, покраска, списание |
| `troya-product-passport-system` | паспорта изделий ПС/РЭ: генератор docx по шаблону TROYA, рисунки, проверка вёрстки |
| `troya-assembly-scheme-system` | схемы сборки картинками в стиле NOMAD V через SOLIDWORKS Composer: стиль листа, карточки, пиктограммы, знаки ISO 7000, проверка сценария, образцы |
| `troya-tech-capabilities` | технологические возможности завода |
| `troya-school-furniture-dimensions` | размеры школьной мебели по ГОСТ |
| `troya-pdm-client-setup` | клиент SOLIDWORKS PDM TROYA на ПК: проверка скриптом, вид хранилища, первый вход, PDM в SOLIDWORKS, общая библиотека Базис, Web2, «Поиск изделия» |
| `troya-workstation-setup` | рабочее место целиком: состав по роли, Python и навыки, PDM, ЕСКД и SWTools, MCP, проверка и отчёт о приёмке |

Навыки ведёт начальник КТО. Свои правки присылайте ему: копии на ПК при следующей установке заменяются.
