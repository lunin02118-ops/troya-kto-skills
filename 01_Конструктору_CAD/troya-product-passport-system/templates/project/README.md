# Генератор паспортов ПС/РЭ — <тема, основание (СЗ № …, заказ …)>

Заведён навыком `troya-product-passport-system`. Готовые паспорта: `<папка вывода>`.

## Запуск

```
python -P -E figures\fig_01.py figures\out      # рисунки (и остальные fig_*.py)
python -P -E build.py "<папка вывода>"          # все изделия
python -P -E build.py "<папка вывода>" 01 03    # отдельные изделия по ключу
```

Перезапуск перезаписывает docx в папке вывода. Если паспорт правили вручную в Word, сначала перенести
правки в `products.py`.

## Файлы

- `products.py` — данные изделий (тексты, характеристики, комплектность, сборка, рисунки).
- `common.py`, `passport_lib.py`, `build.py`, `Шаблон_паспорта_TROYA.docx` — движок и шаблон (копия из навыка).
- `figures\fig_*.py` — рисунки; `figures\out` — PNG; `figures\out\Архив` — прежние рисунки.
- `Архив` — копии `products.py` и рисунков перед правками (`<файл>_до_<что меняли>.py.bak`).
