# Генератор паспортов ПС/РЭ — стулья ученические Nomad (СТ.NM.0001–0003)

Заведён навыком `troya-product-passport-system` 11.11.2026 по поручению владельца: «паспорта нужно
скорректировать все по шаблонам, по которым делали паспорта ранее». Готовые паспорта:
`<WORK>\07_Документация_изделий\01_Паспорта\Nomad_стулья`.

| Ключ | Шифр КД | Изделие | Регулировка | Высота сиденья, мм |
|---|---|---|---|---|
| 01 | СТ.NM.0001.00.000 | Стул Nomad V NC3-5V | плавная, ручкой (винтовой механизм) | 340–420 |
| 02 | СТ.NM.0002.00.000 | Стул Nomad V NC5-7V | плавная, ручкой (винтовой механизм) | 420–500 |
| 03 | СТ.NM.0003.00.000 | Стул Nomad NC3-7R | ступенчатая, шаг 40 мм | 340/380/420/460/500 |

## Запуск

```
python -P -E figures\fig_nomad.py figures\out   # рисунки — листы пошаговых схем сборки
python -P -E build.py "<папка вывода>"          # все изделия
python -P -E build.py "<папка вывода>" 03       # отдельное изделие
```

Перезапуск перезаписывает docx в папке вывода. Если паспорт правили вручную в Word, сначала перенести
правки в `products.py`.

## Файлы

- `products.py` — данные изделий. `COMMON` — общее для трёх стульев, `nomad_v(...)` — оба Nomad V
  (отличаются ростовыми группами, высотами и массой), `P3` — NC3-7R.
- `figures\fig_nomad.py` — рисунки паспорта вырезаются из пошаговых схем сборки (PDF) по листам:
  обложка, комплект деталей (рис. 1) и шаги сборки (рис. 2…). Буквы деталей в колонке «Рис.» таблицы
  комплектности — те же, что на схеме. Колонтитул схемы (ниже `FOOT = 555` пт) отрезается, белые поля
  обрезаются.
- `common.py`, `passport_lib.py`, `build.py`, `Шаблон_паспорта_TROYA.docx` — движок и шаблон (копия из навыка).

## Решения

- 11.11.2026 — шаблон оформления — «Паспорт стул Nomad.docx» (из него сделан шаблон навыка); состав
  разделов и формулировки для стула — по генератору паспортов 840 (стул ученический регулируемый,
  `99_Служебное\Паспорта_840_по_ТС_2026-10-30\products_840.py`, `P840_STUL`).
- 11.11.2026 — шифр КД (СТ.NM.000N.00.000) вместо старых артикулов CSN3-7R и «Комплект Nomad-V»:
  обложка, вводный абзац, подпись рис. 1, свидетельство, колонтитул, имя файла.
- 11.11.2026 — шурупы сиденья и спинки у всех трёх стульев — DIN 968 4,2×16, 4 шт. (2 сиденье + 2 спинка).
  Сверено по моделям SolidWorks и обеим схемам сборки. В старом паспорте Nomad стояли 4,2×16 ×2 и 4,2×30 ×2 —
  это устарело.
- 11.11.2026 — Nomad V: крепёж по модели — винт ISO 7380-2 М8×30 ×4 (два из них установлены на заводе,
  удерживают редуктор), ISO 7380-1 М8×12 ×2, вал шестигранный 400 мм, шайба ×2, заглушка ×2. Ручка
  регулировки в комплект стула не входит, поставляется отдельно на партию.
- 11.11.2026 — NC3-7R: моменты затяжки из КД — шурупы сиденья 1…1,2 Н·м, шурупы спинки в стойку 2…3 Н·м.
- 11.11.2026 — масса — по модели с округлением вверх: Nomad V 11,4 / 11,6 → 12 кг, NC3-7R 10,58 → 11 кг.
- Открытые вопросы (жёлтое):
  - место ярлыка маркировки — «на перемычке металлокаркаса»;
  - количество мест упаковки и габариты упаковки — `1 / …`;
  - NC3-7R: габаритная высота 670 / 710 / 780 / 860 / 900 взята из старого паспорта, а по КД для 6-й
    группы — 825.
