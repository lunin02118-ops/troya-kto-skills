# Навыки ИИ-агентов техотдела TROYA

Навыки (skills) для ИИ-агентов Claude Code, Codex и Antigravity (Gemini). Их ведёт конструкторско-технологический
отдел ТОО «Компания TROYA» (Павлодар, мебель для образования). С навыками агент:
- оформляет чертежи по ЕСКД в SolidWorks и работает с КОМПАС-3D;
- раскладывает файлы заказа по структуре папок и следит за порядком в заявках;
- проверяет технологичность и готовит заявки в цеха;
- делает паспорта изделий.

Это открытая версия пакета для конструкторов. Внутренние пути, имена сотрудников и заказчиков в ней заменены
заглушками. Рабочая версия ведётся в отделе, а этот репозиторий пересобирается из неё.

## Навыки

| Навык | Что делает |
|---|---|
| `eskd-drawings` | чертежи деталей и сборок по ЕСКД в SolidWorks: размеры, швы, позиции, ТТ, спецификация |
| `solidworks-drawing-operator` | подготовка и проверка чертежей SolidWorks |
| `kompas-mcp-operator` | работа агента с КОМПАС-3D через MCP |
| `cad-assembly-structure-organizer` | файлы сборки и проверка CAD-ссылок |
| `cad-material-assignment-system` | проверка материалов деталей по геометрии |
| `kto-folders` | структура папки заказа и раскладка файлов |
| `cad-requests-management-system` | аудит и порядок в папке заявок на сервере |
| `troya-production-documentation-system` | заявки в цеха: раскрой, сварка, покраска, списание |
| `troya-tech-capabilities` | технологические возможности завода, DFM |
| `troya-school-furniture-dimensions` | размеры школьной мебели по ГОСТ |
| `troya-product-passport-system` | паспорта изделий ПС/РЭ: генератор docx, рисунки, проверка вёрстки |

`cad-assembly-structure-organizer` подключается к SolidWorks через модуль из открытого проекта
github.com/wzyn20051216/solidworks-automation-skill (MIT): три файла лежат в его папке `scripts`, лицензия —
`LICENSE_sw_connect.txt` там же. Ставить сам проект не нужно.

## Как поставить

1. Нужны Python 3 и хотя бы один агент на ПК.
2. Скачать репозиторий и запустить `Установить.cmd`. Навыки скопируются в `~\.claude\skills`, `~\.codex\skills`
   и `~\.gemini\config\skills`, а прежние копии сохранятся в `.skill-sync-backups`. Посмотреть, что изменится,
   ничего не меняя, — `Проверить.cmd`.
3. Перезапустить агента.

Можно и вручную: скопировать нужные папки из `01_Конструктору_CAD` в папку навыков агента.

## Заглушки

| Заглушка | Что подставить |
|---|---|
| `<СЕТЬ_КО>` | сетевая папка конструкторского отдела (заявки, библиотека проектирования, нормативная база) |
| `<СЕРВЕР>` | сетевой сервер отдела |
| `<WORK>` | рабочая папка конструктора на ПК |
| `<ФИО>`, `<заказчик>`, `<проект>` | имена людей и организаций в примерах |
| `У00000XXXXX` | код номенклатуры 1С |

Пути по умолчанию в скриптах тоже заменены заглушками. Перед работой укажите свои пути в аргументах скрипта
или в константах в его начале.
